{% if LANGUAGE_CODE == 'ar' %}فكرة SmartGrad{% else %}The idea behind SmartGrad{% endif %}

{% if LANGUAGE_CODE == 'ar' %} SmartGrad منصة أكاديمية تساعد الطلاب والمشرفين على إدارة مشاريع التخرج والعمل الجماعي من مكان واحد. يمكن للطلاب تكوين مجموعات دراسية، والانضمام إليها، وتوزيع المهام ومتابعة مواعيدها وتسليم الملفات، بينما يستطيع المشرفون متابعة تقدم المجموعات والطلاب. {% else %} SmartGrad is an academic platform that helps students and supervisors manage graduation projects and collaborative work in one place. Students can create and join study groups, divide work into tasks, track deadlines, and submit files, while supervisors follow the progress of groups and students. {% endif %}

{% if LANGUAGE_CODE == 'ar' %}كيف تساعد المنصة؟{% else %}How the platform helps{% endif %}

{% if LANGUAGE_CODE == 'ar' %} تجمع المنصة المهام والتسليمات ومؤشرات الإنجاز في مساحة منظمة، وترسل إشعارات فورية بالتحديثات المهمة. كما تقدم تحليلات وملخصات وتوصيات مدعومة بالذكاء الاصطناعي لمساعدة الفريق على معرفة الأولويات ومواطن التأخر. وتعتمد هذه التحليلات على مؤشرات مجمعة، لا على أسماء الطلاب أو أرقامهم الجامعية. {% else %} The platform brings tasks, submissions, and progress indicators into an organized workspace and sends real-time notifications about important updates. AI-assisted analytics, summaries, and recommendations help teams identify priorities and delays. These analytics use aggregated indicators rather than student names or university IDs. {% endif %}

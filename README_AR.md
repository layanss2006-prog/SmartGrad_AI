# SmartGrad AI Platform — النسخة المطوّرة

## دليل النشر على PythonAnywhere

دليل إعداد الاستضافة خطوة بخطوة موجود في ملف [DEPLOY_PYTHONANYWHERE_AR.md](DEPLOY_PYTHONANYWHERE_AR.md).

منصة لإدارة مجموعات الطلاب والمهام والتسليمات، مع إشعارات WebSocket وتحليلات أكاديمية بمساعدة نموذج ذكاء اصطناعي.

## المتطلبات
- Python 3.10 أو أحدث (يفضل 3.11/3.12)
- Visual Studio Code
- Redis للتشغيل متعدد العمليات والإنتاج. أثناء التطوير المحلي يمكن ترك `REDIS_URL` فارغاً واستخدام InMemoryChannelLayer.
- مفتاح OpenAI API اختياري للتحليل الذكي الخارجي. عند عدم وجوده تعمل التحليلات المحلية.

## تشغيل Windows من VS Code

افتح مجلد `SmartGrad` في VS Code ثم Terminal:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

انسخ `.env.example` إلى `.env`، ثم عدّل القيم:

```env
SECRET_KEY=ضع_قيمة_عشوائية_طويلة
DEBUG=True
ALLOWED_HOSTS=127.0.0.1,localhost
OPENAI_API_KEY=ضع_مفتاح_OpenAI_هنا
OPENAI_MODEL=gpt-4o-mini
REDIS_URL=
```

للتشغيل المحلي اترك `REDIS_URL` فارغاً. للإنتاج شغّل Redis واستخدم مثلاً `REDIS_URL=redis://127.0.0.1:6379/0`.

ثم نفّذ:

```powershell
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

افتح `http://127.0.0.1:8000/`.

## ما تم تطويره

### 1) الإشعارات اللحظية
- Django Channels وWebSocket على المسار `/ws/notifications/`.
- كل مستخدم يستقبل إشعاراته الخاصة فقط عبر مجموعة `user_<id>`.
- إشعار فوري عند طلب الانضمام، قبول العضوية، إسناد مهمة، تحديث الحالة ورفع التسليم.
- Redis مدعوم لتشغيل عدة workers/instances، وذاكرة داخلية للتطوير فقط.
- يتم حفظ الإشعار في قاعدة البيانات حتى إذا تعذر إرسال WebSocket.

### 2) محادثة المجموعات
- غرفة محادثة فورية داخل صفحة كل مجموعة، تجمع الطلاب وأعضاء الإشراف المرتبطين بها.
- تُحفظ الرسائل في قاعدة البيانات وتظهر الرسائل الأخيرة عند فتح صفحة المجموعة.
- لا يستطيع قراءة المحادثة أو إرسال الرسائل إلا أعضاء المجموعة وقائدها ومشرفوها.
- الحد الأقصى للرسالة 2000 حرف، وتعمل المحادثة عبر WebSocket على المسار `/ws/groups/<group_id>/chat/`.

### 3) تحليلات الذكاء الاصطناعي
- نسبة إنجاز المجموعة.
- عدد المهام المكتملة وقيد التنفيذ وغير المبدوءة.
- المهام المتأخرة والمستحقة خلال ثلاثة أيام.
- توصيات وأولويات مختصرة من OpenAI عند إعداد المفتاح.
- لا تُرسل أسماء الطلاب أو أرقامهم الجامعية أو أوصاف المهام إلى النموذج؛ ترسل مؤشرات مجمعة فقط.
- تحليل محلي احتياطي عند غياب المفتاح أو تعطل الخدمة.

**النموذج المستخدم افتراضياً:** `gpt-4o-mini` من خلال OpenAI API. يتطلب ذلك مفتاح API صالحاً وفوترة/رصيداً متاحاً في حساب مزود الخدمة. لا يوجد مفتاح API مضمّن في المشروع.

### 4) الصلاحيات
- التسجيل العام ينشئ حساب طالب فقط.
- إنشاء حسابات المشرفين يتم من Django Admin بواسطة مدير النظام.
- الطالب يرى المجموعات التي ينتمي إليها فقط.
- قائدة المجموعة أو المشرف المضاف للمجموعة يدير العضوية والمهام.
- المشرف غير المرتبط بالمجموعة لا يستطيع الاطلاع عليها أو تعديلها.
- الطالبة تحدّث المهام المسندة إليها فقط.
- قرارات قبول/رفض العضوية تستخدم POST مع CSRF بدلاً من روابط GET.

### 5) حماية الملفات
- حد أقصى 10 MB.
- قائمة امتدادات مسموحة للملفات الأكاديمية.
- التحقق من تواقيع PDF والصور وملفات Office بدلاً من الثقة بالامتداد وحده.
- منع عرض مجلد الوسائط الخاص مباشرة عبر مسار عام.
- تنزيل التسليمات من View يتحقق من عضوية المجموعة.
- إعدادات حماية إضافية عند `DEBUG=False`.

### 6) الاختبارات
شغّل الاختبارات:

```powershell
python manage.py test
```

الاختبارات تغطي صلاحيات المجموعات، منع التسجيل كمشرف، تحديث المهام، طلبات الانضمام، التحقق من الملفات، التحليلات، وبث الإشعارات.

## إنشاء حساب مشرف
1. شغّل `python manage.py createsuperuser`.
2. افتح `/admin/`.
3. من Users أنشئ المستخدم، وحدد `role = teacher` واحفظ.
4. أضف المشرف إلى المجموعة من حساب قائدة المجموعة.

## تنبيهات قبل النشر الفعلي
- استخدم PostgreSQL بدلاً من SQLite عند النشر.
- شغّل Redis وASGI server مثل Daphne/Uvicorn، ولا تعتمد على `runserver` للإنتاج.
- اجعل `DEBUG=False` واضبط `ALLOWED_HOSTS` وHTTPS و`SECRET_KEY`.
- ضع ملفات التسليم خارج أي مجلد static/public، ويفضل فحصها بمكافحة البرمجيات الخبيثة في بيئة الإنتاج.
- راجع سياسة الخصوصية وموافقة المستخدم قبل إرسال أي بيانات إلى مزود AI.
- الإشعارات اللحظية تعمل فقط أثناء اتصال المستخدم بالصفحة؛ أما الإشعارات المخزنة فتظهر عند فتح لوحة التحكم.

## الملفات الأساسية المضافة
- `core/consumers.py`, `core/routing.py`, `core/signals.py`: WebSocket.
- `core/ai.py`: التحليلات الذكية.
- `core/permissions.py`: قواعد الوصول.
- `core/validators.py`: التحقق من الملفات.
- `core/test_upgrade.py`: اختبارات التطوير.
- `config/asgi.py`: تشغيل HTTP وWebSocket.
